Format each question like this (blank line between questions):

1. Question text?

B) second option

Optional extra lines per question:
Topic: some topic name — used for the strong/weak breakdown after a test.
Explanation: why B is correct — shown on the results page.

The parser is fairly tolerant of "1)" vs "1.", "A." vs "A)", and "Correct answer:" vs "Answer:" — but if a block can't be understood it will be skipped and listed, so nothing gets added silently wrong.
